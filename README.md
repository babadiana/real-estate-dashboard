# Приложение для анализа рынка первичной жилой недвижимости

> Репозиторий содержит описание аналитических методов, функциональности и пользовательских сценариев приложения. Исходный код и набор рыночных данных не опубликованы; приложение нельзя запустить из этого репозитория.

## Задача

Оперативный анализ рынка новостроек требует подготовки разнородных данных, расчёта показателей, сравнения объектов и интерпретации изменений. Цель проекта – объединить эти операции в интерактивной аналитической системе для аналитика и руководителя коммерческого отдела.

## Технологии

- **Python, Pandas, NumPy:** подготовка и обработка данных, расчёт показателей и аналитических сравнений.
- **Streamlit:** интерактивный интерфейс с отдельными режимами «Аналитик» и «Руководитель».
- **Plotly:** интерактивные графики и визуальное сравнение показателей.

## Аналитический процесс

1. **Загрузка и подготовка данных.** Чтение CSV, нормализация названий полей, приведение дат и чисел к корректным типам, обработка пропусков и удаление дубликатов.
2. **KPI рынка.** Количество уникальных квартир, ЖК, застройщиков и районов; средняя и медианная цена за м², средняя стоимость квартиры и площадь.
3. **Динамика и конкуренты.** Сравнение выбранных периодов, цен, структуры и ротации предложения; сопоставление целевого объекта с базой сравнения.
4. **Рейтинги.** Сравнение порядка объектов между периодами с использованием расстояния Кемени для общих элементов рейтингов.
5. **Маркетинговые сигналы.** Формирование рекомендаций на основе рассчитанных изменений и сравнительных показателей; вывод результатов в аналитическом интерфейсе.

## Что демонстрирует кейс

- Преобразование бизнес-задачи в набор измеримых KPI и аналитических срезов.
- Подготовку данных для воспроизводимого сравнения рыночных показателей.
- Анализ динамики и конкурентной среды с интерактивной визуализацией.
- Переход от расчётов к интерпретации показателей и маркетинговым рекомендациям.

## Ограничения

Репозиторий представляет **документацию и визуальную демонстрацию**, а не публичный исходный код или развёрнутое приложение. Анализ динамики предложения основан на сравнении данных за разные периоды и не позволяет достоверно определить количество фактических продаж.
